- 全部升级前用户的监控权限为 `approved`。

- 普通账号不能调用管理员接口；批量调频混入其他用户收藏、重复 ID 或非法间隔时不产生部分更新。
- 相同频率的 no-op 不新增通知或审计；关闭收藏仍不设置下次检查，目标价和提醒开关保持不变。

## API 与邮件

- 覆盖未验证邮箱、未申请、审核中、驳回、重新申请、批准及重复申请/审批。
- 验证邮箱后权限仍为 `not_requested`；查询、关闭监控的收藏和手动操作不受审批阻断。
- 通知默认只发站内消息；不可用收件人开启同步邮件时整体拒绝。
- 定向通知正确创建邮件 Outbox；广播只创建一条站内广播，隔离样本中 3 个合格普通用户入队、2 个不合格普通用户跳过。
- 使用真实 `smtplib` SMTP 协议连接隔离捕获服务，确认 Worker 实际发送，而非只检查队列表；投递前换绑邮箱后使用最新已验证地址。
- 浏览器流程结束后，以用户身份确认审批、驳回、调频及定向消息实际可见，再驱动 Outbox 投递定向邮件并确认本站相对动作链接已转换为绝对地址。
- 邮件内容转义、SMTP 未配置、收件人失效取消及同批多封邮件间重新读取用户状态由后端测试覆盖。
